# learningproject-dbportal

> **Reminder:**  
Make sure to add the environment variable `NEXT_PUBLIC_CONTROLSERVERAPI` to your configuration before running the project.

## Setup

1. Clone the repository.
2. Install dependencies.
3. Add the required environment variable:
    ```env
    NEXT_PUBLIC_CONTROLSERVERAPI=your_api_url_here
    ```
4. Start the development server.

## Usage

Follow the setup instructions above to get started.
